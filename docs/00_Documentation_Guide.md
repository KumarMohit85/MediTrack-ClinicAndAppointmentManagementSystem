# MediTrack – Documentation Guide

## Purpose
This documentation set is prepared for the **MediTrack – Clinic and Appointment Management System** Java project. It is organized to map directly to the assignment requirements and to provide material suitable for submission, demonstration, and viva.

## Documents
| File | Purpose |
|---|---|
| `01_Setup_Instructions.md` | Java/JDK setup, compilation and execution |
| `02_JVM_Report.md` | JVM architecture, class loading, runtime areas, execution engine, JIT and WORA |
| `03_Requirements_Traceability.md` | Requirement-by-requirement mapping to project artifacts |
| `04_System_Architecture.md` | Layered architecture and responsibility of packages/classes |
| `05_Design_Decisions.md` | OOP, collections, cloning, immutability, patterns and implementation choices |
| `06_User_Guide.md` | Menu-driven CLI and application usage |
| `07_Test_Plan.md` | Manual/smoke testing strategy and expected results |
| `08_Submission_Checklist.md` | Final submission checklist |
| `UML/` | Class/package UML diagrams |
| `Flowcharts/` | Application and feature flowcharts |
| `Architecture/` | High-level architecture diagrams |

## Requirement coverage
The documentation covers the assignment areas: Java/JVM, package organization, OOP, collections/generics, exceptions, file I/O/CSV, concurrency, design patterns, streams/lambdas, CLI, testing, Javadocs and Git.

> **Important:** Documentation describes the required/target design. Before final submission, the source code should be compiled and the smoke-test results should be captured against the exact repository version being submitted.
